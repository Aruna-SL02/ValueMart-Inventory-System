# 🏬 Valuemart Inventory Management System

A clean, scalable, and efficient **Inventory Management System** designed for small and medium-scale businesses.  
Valuemart IMS helps store owners track stock, manage products, record transactions, and monitor sales using a professional **MVC Architecture** for easy maintenance and expansion.

---

## 🧱 MVC Architecture

This project is built using the **Model–View–Controller (MVC)** architectural pattern:

### **📘 Model**
Handles all data-related operations:
- Database CRUD
- Product & stock management
- Sales/transaction logic
- User authentication data

### **📗 View**
User interface components:
- HTML/CSS pages
- Dynamic templates
- Reusable UI components (header, footer, layout)

### **📙 Controller**
Connects Models & Views:
- Handles user requests
- Processes form submissions
- Controls page navigation
- Validates and sends data to Views

✔ Ensures **clean code**, **easy maintenance**, and **scalability** for future improvements.

---

## ✨ Features

### 📦 Inventory & Product Management
- Add, edit, delete products
- Real-time stock tracking
- Low stock alerts
- Product categorization
- SKU / barcode support

### 🛒 Sales Management
- Create and record sales
- Auto inventory deduction
- Sales summary & filtering

### 📊 Dashboard & Analytics
- Stock overview
- Best-selling items
- Daily/Monthly sales chart (Chart.js)
- Performance indicators

### 👥 User Authentication
- Admin and Staff roles
- Secure login system (MVC-controlled)
- Permission-based access

### 🧩 System Utilities
- Database backup (optional)
- Settings management
- Responsive UI (Bootstrap)

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Framework / UI:** Bootstrap  
- **Backend:** PHP (MVC structured)  
- **Database:** MySQL  
- **Charts:** Chart.js  
- **Architecture:** Pure MVC (No frameworks)  
- **Version Control:** Git & GitHub
